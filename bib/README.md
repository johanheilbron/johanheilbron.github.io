# bib: PDFs of Johan's publications

Put PDFs in the folder that matches the section of the publication list:

| Folder | What goes in it |
|---|---|
| `books/` | Books, edited volumes, brochures |
| `scientific-editions/` | Scientific editions (Bourdieu, Elias, ...) |
| `articles-chapters/` | Articles, book chapters, reviews, essays |
| `journal-issues/` | Thematic journal issues |
| `film/` | Anything belonging to the filmography |

File names do not matter: any name is fine. Files are not renamed afterwards.

A PDF only appears on the website once it has been **linked** to its entry in the
publication list. That is done by the sync routine described in `CLAUDE.md`
(ask Claude: *"sync the website"*). PDFs that could not be matched with certainty are
listed in `bib/UNMATCHED.md`.

Size: keep single files under 20 MB where possible (github.com accepts uploads up to 25 MB),
and all PDFs together under about 700 MB.
